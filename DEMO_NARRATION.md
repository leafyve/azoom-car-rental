# AZoom Car Rental - Screen Recording Narration

The accompanying 96-second MP4 is an **automated demonstration with synthetic narration**. If your lecturer expects your own spoken explanation, record your own voice using this short script, then upload the recording to Google Drive.

1. **Homepage**: This is AZoom Car Rental, an electric-car rental website. Customers can search by dates and start a reservation.
2. **Fleet**: The fleet displays six example electric vehicles. I can filter by body type, sort by price and select the MG4 Electric.
3. **Reservation**: I enter the customer's name, email and phone number, choose the Marina Bay office, and confirm the rental dates.
4. **Pricing**: JavaScript updates the rental estimate. Three days at S$92 cost S$276 before GST and S$300.84 including GST.
5. **Credit card**: The reservation uses a demo Visa or Mastercard selection. No real card numbers or charges are processed.
6. **Confirmation**: A reference number is generated. The booking is stored in browser localStorage for the demonstration.
7. **Rental journey**: I can simulate car collection at the office, return to the designated car park and employee inspection.
8. **Final bill**: If damage is found, the charge is added to the rental amount. The final bill is payable using the simulated credit card action.
9. **Conclusion**: This demonstrates the main business processes using HTML, CSS and JavaScript, without a backend database.
